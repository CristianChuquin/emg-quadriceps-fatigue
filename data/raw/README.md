# Raw dataset (not committed)

Place the raw sEMG recordings here, one folder per participant:

```
data/raw/sujeto1/R1_dr_sujeto1.csv
data/raw/sujeto1/R1_iz_sujeto1.csv
...
data/raw/sujeto15/R5_iz_sujeto15.csv
```

- `R1`–`R5`: repetition block; `dr` / `iz`: right / left leg.
- Each CSV has the columns `Relative_Time_s`, `ADC_Value`, `Voltage_mV` (1000 Hz).
- The dataset was distributed by the course instructor and is not redistributed here.
